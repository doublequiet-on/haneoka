# D1 结构与迁移 · L2-2

上级：[地图](../L2.md)。

## 职责

保存 Worker 的目标数据库结构和已提交的生产迁移；操作步骤由 [数据库 README](README.md) 唯一维护。

- [schema.sql](schema.sql)：新数据库目标结构。
- [migrations](migrations/)：按序应用的生产历史；已应用迁移不可重写。
- [数据库工具](../../scripts/database/L2-2.md)：本地快照、计划及应用，不替代部署迁移。

账户、社区、上传、审核、配队库存和事件历史等表由对应 Worker handler 使用；D1 访问经准备语句及请求会话。生产部署工作流可应用待执行迁移，不能把文档或源码合并等同无远端副作用。

[抽卡历史 handler](../gacha-history.ts) 使用[0032 迁移](migrations/0032_gacha_history_cloud.sql)中的 owner 私有白名单 collection、CAS revision 与刷新序号；游戏凭据不进入该文档。

结构变更同时维护新迁移和目标 schema，并检查读写者及旧版本兼容。原型重置迁移的历史特殊性见 README，不将其扩展为一般可删除数据的许可。本地计划、导出、行数据和数据库文件留在忽略目录。验证见 [开发导航](../../docs/DEV_GUIDE.md)。

[0037 迁移](migrations/0037_community_charts.sql) 保存社区谱面 head、独立的写入 version 与 published revision，以及版本素材引用、音频对象、点赞与可重试回收队列；撤回／删除推进 version 并收窄讨论访问，旧发布请求因此失效。谱面正文和编译后的 Sonolus LevelData 在上传 R2。

[0038 迁移](migrations/0038_community_chart_analysis.sql) 按谱面版本和模型版本保存服务端生成的分析。保存工程、读取列表及授权读取历史详情时生成，定时任务逐批补全当前公开版本；失败的空结果至少间隔一小时重试，成功结果不被失败覆盖。v4 重算期间，公开版本可暂用相同谱面版本的 v1–v3 基础统计，不使用旧推荐值；作者等级与模型推荐值分别保存。

[0039 迁移](migrations/0039_community_chart_media_snapshots.sql) 保存服务器素材快照、版本引用和来源索引；素材对象按内容去重，版本删除后才参与回收，不依赖正式资源 release 保留期限。

[0040 迁移](migrations/0040_official_ranking_cloud.sql) 为官方活动采集保存独立区服目录、高水位、挑战身份和观测索引；正文在私有榜单 R2，成功与失败观测共用数字游标，最新榜单只读取成功记录。重试按区服和 snapshot ID 去重，读取保留原始接收时间；旧 Moenotes 历史不迁移或重标。

[0041 迁移](migrations/0041_official_arena_rankings.sql) 为竞技场联赛保存官方名次窗口索引（赛季、乐队、起止名次、榜内人数），正文同样在私有榜单 R2；读取取对齐百名窗口的最新成功观测。

[0042 迁移](migrations/0042_official_arena_population.sql) 保存竞技场联赛完整阈值人数快照索引，并为联赛最新人数／窗口元数据建立索引，每窗口一条紧凑玩家 ID／位置索引使搜索命中只读取一份 R2；正文仍在私有 R2，公开 GET 不执行人口二分或游戏请求。
