# Astro 文档与页面壳 · L2-2

上级：[地图](../L2.md)。

## 职责与结构

[AppShell.astro](AppShell.astro) 拥有应用栏、全局导航和页面壳；导航分组与子分支可折叠，保留链接入口并保存展开选择；[Base.astro](../layouts/Base.astro) 是文档基础布局。Document 组件连接页面数据、SSR、脚本和样式，`entities/`、`pages/` 组合具体页面。

| 入口 | 责任 |
| --- | --- |
| [RouteDocument.astro](RouteDocument.astro) | 依据路由定义组合页面 |
| [CommunityDocument.astro](CommunityDocument.astro)、[StoryDocument.astro](StoryDocument.astro) | 社区与故事文档 |
| [CommunityChartsDocument.astro](CommunityChartsDocument.astro)、[entities/CommunityChartEntityPage.astro](entities/CommunityChartEntityPage.astro) | 社区谱面集合、动态实体和播放器子页共用壳；用户谱面不进入静态资料载荷 |
| [entities/CatalogEntityPage.astro](entities/CatalogEntityPage.astro) | 资料实体页面组合；最终 payload 由 [共享 projector](../server/catalog-page-projector.ts) 生成 |
| [pages/TeamBuilderPage.astro](pages/TeamBuilderPage.astro) | 配队页面数据、样式和工作区挂载 |
| [LevelExperienceDocument.astro](LevelExperienceDocument.astro) | 账号与统一角色羁绊等级经验表，读取 progression 并复用共享数字表格；显示单级所需经验和累计经验 |

数据准备属于 [Server](../server/L2-2.md)，交互属于 [Lit](../lit/L2-2.md)，界面与布局约束由 [AGENTS](../../AGENTS.md) 维护。脚本导入可能注册元素并加载运行时，不能只按 Astro 模板文本判断副作用。

改壳要检查 SSR 首屏、应用栏捕获／接管、导航和水合；可见变化按 [开发导航](../../docs/DEV_GUIDE.md) 做桌面、手机及明暗主题验收。
