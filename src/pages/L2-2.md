# Astro 路由 · L2-2

上级：[地图](../L2.md)。

## 职责与入口

路由选择 server、locale、资源类型和实体，调用 Document 组件及构建数据。`getStaticPaths` 不是单纯 URL 枚举：它可读取资料、登记构建覆盖并依赖静态输入。

| 路由 | 责任 |
| --- | --- |
| [[server]/[locale]/[kind]/index.astro](%5Bserver%5D/%5Blocale%5D/%5Bkind%5D/index.astro) | 资源集合与特殊资源分派 |
| [[server]/[locale]/[kind]/[id].astro](%5Bserver%5D/%5Blocale%5D/%5Bkind%5D/%5Bid%5D.astro) | 规范实体页 |
| [[locale]/[...slug].astro](%5Blocale%5D/%5B...slug%5D.astro) | 通用语言路由 |
| [[server]/[locale]/player-ranks/index.astro](%5Bserver%5D/%5Blocale%5D/player-ranks/index.astro)、[friendship-ranks/index.astro](%5Bserver%5D/%5Blocale%5D/friendship-ranks/index.astro) | 图鉴账号与角色羁绊经验表的独立静态页，与录音室练习一样不生成逐级实体页 |
| [provider-static](provider-static/)、[static-views](static-views/)、[asset-static](asset-static/)、[playlist-static](playlist-static/) | 内部物理构建路径；公开地址经过共享路由和 Worker 还原 |
| [i18n](i18n/) | 按内容版本／语言／命名空间输出消息 |

正式静态页面的服务器选择见 [entity-graph.ts](../lib/entity-graph.ts) 和构建环境。新增资源类型同时核对 [resource-route.ts](../lib/resource-route.ts)、导航、页面载荷和 Worker。

`charts` 为社区谱面集合。动态 UUID 实体及其 `chart/` 播放器子页共用 `[kind]/[id].astro` 生成的 `_` 空壳，规范地址在共享静态文档查找和开发重写中映射到该壳；实体和指定版本播放数据由带权限的社区 API 读取。

开发模式重写及生产静态文档打包见 [middleware](../middleware.ts) 与 [Server](../server/L2-2.md)。布局规则见 [Components](../components/L2-2.md)。验证按 [开发导航](../../docs/DEV_GUIDE.md)。
